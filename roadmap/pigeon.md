# Pigeon Roadmap

[Pigeon] is ROOST's model translation layer: a standard for model specs that enables plug-and-play interoperability with open-weight safety models. Pigeon supports the Detection capability by making it easier to swap and combine models across the [ROOST Model Community](rmc.md) and partner ecosystems.

This roadmap covers Pigeon's planned work. For the strategic context behind these priorities, see the [overall ROOST roadmap](../roadmap.md).

## Now {.badge-now}

* [**Align on approach for Pigeon (Model Translation Layer)**](https://github.com/roostorg/pigeon/milestone/1)**:** Standardize model specs to enable plug-and-play interoperability with open-weight safety models.
