# Osprey Roadmap

[Osprey] is ROOST's real-time rules engine: human-crafted rules actioned at scale, high-QPS processing for streaming and batched data, open-ended investigation, and a UI for analysts to identify abuse patterns and signals. It supports sync and async rule creation and execution. Osprey was built and donated by [Discord](https://discord.com/blog/osprey-open-sourcing-our-rule-engine) and open sourced through ROOST.

This roadmap covers Osprey's planned work. For the strategic context behind these priorities, see the [overall ROOST roadmap](../roadmap.md).

## Now {.badge-now}

* [**Analyst Self-Service Tools**](https://github.com/roostorg/osprey/milestone/4)**:** Implement code-free rules management and LLM-assisted recommendations to streamline rule authoring and investigation.

* [**Adopter Readiness & Cloud Portability**](https://github.com/roostorg/osprey/milestone/6)**:** Enable GCP-independent operations by implementing hermetic image builds, versioned PostgreSQL schema migrations, and pluggable identity/access audit trails for sovereign deployments.

## Next {.badge-next}

* [**Real-time Rule Execution**](https://github.com/roostorg/osprey/milestone/5)**:** Optimize high-throughput rule engine performance, reduce latency, and ensure real-time stability for streaming data processing.

## Later {.badge-later}

* [**Behavioral Signals & Pattern Detection**](https://github.com/roostorg/osprey/milestone/7)**:** Expand real-time graph analysis, velocity tracking, and network coordination signals to detect complex abuse patterns across entities.

[Osprey]: https://github.com/roostorg/osprey
